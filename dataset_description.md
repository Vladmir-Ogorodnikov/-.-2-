# Что находится в журнале

Журнал полностью синтетический, имитирует нормализованную выгрузку информационной системы. Реальных пользователей, клиентских процессов и документов здесь нет. Заголовки колонок являются форматом учебного CSV, а не контрактом API ELMA365.

Одна строка означает одно наблюдаемое действие: для человеческого задания записано его завершение, для границ экземпляра — соответствующее событие. В этом файле нет отдельной строки создания того же задания. Все представленные истории завершены; отсутствие какой-либо активности нельзя объяснять незавершённостью выгрузки.

| Поле | Значение |
|---|---|
| ProcessInstanceId | UUID одного экземпляра; группируйте строки по этому полю |
| EventId | Уникальный UUID записи |
| EventIndex | Числовой порядок события внутри экземпляра, начиная с 1 |
| ActivityId | Стабильный непрозрачный UUID активности; не код её положения в схеме |
| ActivityName | Читаемое название выполненного действия |
| EventType | process_started — начало; task_completed — завершено человеческое задание; process_completed — завершён экземпляр |
| Timestamp | Время события ISO 8601, часовой пояс +03:00 |
| TaskId | UUID отдельного задания; пустой для автоматических границ |
| UserId | Синтетический UUID фактического исполнителя; пустой для автоматического действия |
| Role | Роль фактического исполнителя; system — автоматическое действие |
| Result | Зафиксированный бизнес-результат действия; не технический ID перехода |
| Amount | Сумма заявки, условные рубли; точка как десятичный разделитель |
| TemplateVersion | Версия определения процесса в выгрузке |

Пустые UserId и TaskId у автоматического события допустимы. Одна ActivityId может повториться внутри экземпляра: это выполнение активности снова, с другим TaskId. Не удаляйте повтор автоматически как дубликат.

Рабочий календарь учебной организации: понедельник–пятница, 09:00–18:00, UTC+03:00. Государственные праздники и обед отдельно не моделируются. Человеческие действия завершаются в рабочее время, автоматические — за секунды. Интервал между соседними завершениями включает очередь, работу и нерабочее время, поэтому не равен точному времени труда сотрудника.

CSV использует запятую, UTF-8 с BOM и заголовок. Для Excel импортируйте через «Данные → Из текста/CSV», выбирайте UTF-8 и запятую. UUID сохраняйте как текст. Внутри экземпляра сортируйте по **числовому** EventIndex, а не лексикографически. Глобальный файл отсортирован по времени: соседние строки файла могут относиться к разным экземплярам.

В журнале есть только наблюдаемые события и контекст заявок. Внутренние определения переходов/шлюзов не передаются. Схему нужно выводить из отдельных историй и их совокупности. Одинаковые секунды разрешаются через EventIndex.
