# Решение: восстановление процесса «Заявка на закупку» по журналу событий

Входные данные: `../students (1).csv` (UTF-8 с BOM, разделитель — запятая; 6 508 событий,
1 000 экземпляров, 12.01–08.07.2026). Описание полей — в `../dataset_description.md`.

## Состав папки

| Файл | Что это |
|---|---|
| `process_map.png` | Схема восстановленного процесса (обязательное приложение) |
| `process_map.mmd` | Та же схема в формате Mermaid (исходный текст) |
| `report.md` | Отчёт на 2–4 страницы (обязательное приложение) |
| `variants.csv` | Таблица полных вариантов (`Variant,Route,NumberOfCases,Share`) — обязательная |
| `student_transitions.csv` | Необязательный CSV переходов (`SourceActivity,TargetActivity`) |
| `analyze.py` | Полный воспроизводимый анализ журнала (pandas); печатает все числа из отчёта и перезаписывает `variants.csv` и `student_transitions.csv` |
| `make_diagram.py` | Генерация `process_map.png` (matplotlib) |
| `bonus_pm4py.py` | Необязательная усложнённая часть: авто-обнаружение модели (PM4Py) и сравнение с ручной |

## Как воспроизвести

```bash
python3 -m venv venv && source venv/bin/activate      # или аналог на Windows
pip install pandas matplotlib                          # bonus_pm4py.py также требует: pip install pm4py
cd solution
python analyze.py        # сводка: частоты, переходы, развилки, варианты; пишет variants.csv и student_transitions.csv
python make_diagram.py   # process_map.png
python bonus_pm4py.py    # опционально: DFG / Inductive Miner / Heuristics Miner
```

Кодировки: вход — UTF-8 BOM; выходные CSV — UTF-8 (без BOM), разделитель — запятая,
разделитель активностей в `Route` — ` > `, доля `Share` — число от 0 до 1; сумма `NumberOfCases` = 1 000 (100 % журнала).

## Ключевые факты (проверяются запуском analyze.py)

- Стартует всегда `Регистрация заявки` (process_started, system), заканчивается — `Заявка выполнена` (911) / `Заявка отклонена` (63) / `Заявка отменена` (26).
- 10 активностей, 12 различных непосредственно следующих пар; 8 вариантов, покрывают 100 % экземпляров.
- Ветка `Дополнительное согласование` (директор) наблюдается ровно для дошедших до «Проверка бюджета» заявок с `Amount ≥ 150 000` (209 из 209; при `Amount < 150 000` — 0 из 702).
- Возврат `Доработка заявки → Первичная проверка`: 174 перехода в 156 экземплярах (15,6 %), не более 2 итераций.
